# DriveEasy Car Rental System

## Description

DriveEasy is a car rental website developed using Python and Flask. It will allow users to view cars and make reservations.

## Technologies

* Python
* Flask
* HTML
* CSS
* JavaScript
* SQLite

## How to Run

1. Activate the virtual environment:

   ```bash
   source .venv/bin/activate
   ```
2. Start the application:

   ```bash
   python3 app.py
   ```
3. Open http://127.0.0.1:5000 in your browser.
